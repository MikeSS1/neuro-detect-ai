# Neuro Detect AI

Neuro Detect AI is an applied machine-learning and computer-vision project focused on assisting medical-image analysis through automated segmentation and detection.

The project explores how deep-learning models can extract meaningful regions from medical imagery and translate model results into an accessible prototype interface for testing and decision support.

## Project Motivation

Medical imaging contains large amounts of visual information that can be difficult and time-consuming to analyze manually. Neuro Detect explores how computer vision can assist this process by identifying and segmenting relevant regions from medical images.

## What I Built

- Computer-vision segmentation pipeline
- YOLO-based model experimentation
- Image preprocessing and inference workflow
- Model evaluation using precision, recall, F1 and confusion matrices
- Visualization of segmentation predictions
- Prototype mobile/application interface
- Deployment-oriented experimentation
